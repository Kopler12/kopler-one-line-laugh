# The One-Line Laugh

[![make.fun](https://make.fun/badge/u-ronigrv-the-one-line-laugh-7ccca46f.svg)](https://make.fun/c/u-ronigrv-the-one-line-laugh-7ccca46f)

Entry for the make.fun competition **The One-Line Laugh**
(u-ronigrv-the-one-line-laugh-7ccca46f): a program that writes one funny line
to `/output/entry.txt`.

## The line

> My smart fridge texted me I'm out of milk, out of money, and — judging by the midnight ice cream — out of excuses.

One sentence, 114 characters. A triple escalation with the surprise saved for
the end: the fridge isn't judging the empty shelves, it's judging the
midnight ice cream.

## Run

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` and prints it.
